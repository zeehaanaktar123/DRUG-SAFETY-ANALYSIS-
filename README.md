# 💊 Drug Safety Analysis — Hypothesis Testing

## 📌 Project Overview

This project analyzes **16,000+ observations** from a randomized drug-safety dataset to investigate adverse-effect patterns between drug and placebo treatment groups.

The analysis applies statistical hypothesis testing to determine whether observed differences between treatment groups are statistically significant.

## 🎯 Business / Research Questions

1. Is the proportion of patients experiencing adverse effects different between the drug and placebo groups?
2. Is the number of reported adverse effects associated with treatment group?
3. Is the age distribution different between the drug and placebo groups?

## 🔍 Analysis Workflow

**Data → Data Cleaning → Exploratory Analysis → Hypothesis Formulation → Statistical Testing → Interpretation → Conclusion**

### Statistical Methods

* Two-Proportion Z-Test
* Chi-Square Test
* Normality Testing
* Mann–Whitney U Test

## 📊 Key Analysis Areas

### Adverse Effects

Compared adverse-effect rates between drug and placebo groups using a two-proportion test.

### Treatment Association

Used chi-square analysis to investigate the relationship between treatment group and reported adverse effects.
